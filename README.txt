V9-FULL exhaustive holdout re-evaluation
=========================================

Purpose
-------
Re-use the exact 24 holdout probes already generated by V9-FULL. Do not generate
new probes and do not retrain the policy. For every probe that originally passed
the benign gate, evaluate it on EVERY matched V6.5 validation pair for its role.
Previously blocked/invalid probes stay blocked/invalid and are reported, not bypassed.

The script reports two views:
1) The original V9 energy-separation grader, now evaluated on all pairs.
2) A matched-pair causal diagnostic for each composition:
     specific_i = d(PLUS_i, MINUS_i) - d(PLUS_i, SHAM_i)
     delta_i    = specific_i(query) - specific_i(anchor)
   with mean / median / 25th percentile and robust median+Q25 summaries.

No Qwen/policy generation is used. Missing MAS responses are filled through the
existing response cache; existing responses are cache hits.

Install
-------
Copy these files into the project, preserving paths:
  scripts/evaluate_v9full_exhaustive_holdout.py
  cluster/v9full_exhaustive_holdout_cpu.sbatch

Plan only (safe on login node; no model/API execution)
------------------------------------------------------
PYTHONPATH="$PWD" python scripts/evaluate_v9full_exhaustive_holdout.py

Actual run (submit; do not execute on login node)
-------------------------------------------------
sbatch cluster/v9full_exhaustive_holdout_cpu.sbatch

Monitor
-------
squeue --me
tail -f "$(ls -t logs/v9-holdout-all-*.out | head -1)"

Outputs
-------
artifacts/v9_full_exhaustive_holdout_rows.jsonl
artifacts/v9_full_exhaustive_holdout_summary.json

After completion, send the SLURM log and summary JSON back for interpretation.
